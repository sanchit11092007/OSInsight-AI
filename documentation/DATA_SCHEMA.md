# Monitoring Data Schema

| Field | Meaning |
|---|---|
| timestamp | UTC ISO-8601 collection time |
| cpu_percent | Overall CPU utilization |
| memory_percent | Virtual memory utilization |
| memory_used_mb | Used memory in megabytes |
| disk_percent | Disk utilization |
| disk_used_gb | Used disk space in gigabytes |
| process_count | Number of process IDs visible to psutil |
